# 报错不入群

LLM/agent 报错时 AstrBot 会直接把原始异常发到会话里；本插件在 send 层拦住，群聊不显示，只写日志并私聊管理员。

> 从个人自用环境里抽出来开源的一份，发布前做过脱敏：所有 QQ 号、群号、本机绝对路径、token 都换成了空值或占位符。
> 装完记得按下面的说明填自己的。

## 安装

放到 AstrBot 的插件目录（`data/plugins/`）下，重载插件或重启 AstrBot 即可。AstrBot 4.22.0+，平台适配器 `aiocqhttp`。

## 配置

需要一个本地桥接配置 `bridge.json`（含 `port` / `token`），放在插件目录下，用来把被拦下来的报错私聊发给管理员。没有这个文件也能跑，只是不发通知。

## 说明

- 依赖 AstrBot 自带的 `astrbot.api`，不需要额外 pip 包。
- 日志写在自己插件目录的 `data/` 下，不会污染别处。
